# v1.0.0 手工验收清单

## 验收范围

- 周期任务创建与编辑均支持配置“每周期目标分钟数”，并以分钟作为统一时间单位。
- 周期任务列表主操作为“开始计时”，列表展示当前周期目标时间、已完成时间、剩余时间、完成率和最近一条时间记录。
- 计时弹窗支持暂停、继续、结束并记录；退出已超过 1 分钟的计时应进入记录保存流程，而不是直接丢弃。
- 保存时间记录时可填写进展说明，记录保存后当前周期累计完成分钟数同步更新。
- 刷新或异常退出后，未完成的计时会话可恢复、保存为时间记录或丢弃。
- 周期任务详情按周期展示历史时间记录，记录说明可修改，记录可删除。
- 当前周期累计分钟数达到目标后，周期任务应视为当前周期已达标；未达标且到提醒条件时才产生周期提醒。
- 两段不连续时间记录保持为两条独立记录，累计分钟数用于完成率和达标判断。
- 任务概览展示全部周期任务的目标分钟、已完成分钟、剩余分钟，以及各周期任务的最近时间记录。

## 发布验收

- `package.json`、`package-lock.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock` 与 `src-tauri/tauri.conf.json` 版本号统一为 `1.0.0`。
- Windows 发布产物必须包含 NSIS 安装包与 MSI 安装包，文件名版本号为 `1.0.0`。
- Git tag 与 GitHub Release 使用 `v1.0.0`。
