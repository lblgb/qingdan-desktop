# v0.9.0 手工验收清单

## 验收范围

- 周期任务在任务清单内通过“普通任务 / 周期任务”切换查看，不再作为独立入口。
- 新建入口支持创建周期任务，周期可按分钟、小时、天、周配置。
- 周期任务列表优先展示“提交进展”，并提供详情、编辑、删除能力。
- 详情弹窗展示当前周期摘要与历史进展记录，历史记录可修改。
- 当前周期无进展时可进入待提交状态，用于后续提醒逻辑。
- 普通任务与周期任务均使用到分钟的时间粒度。
- 周期任务相关弹窗、下拉、按钮与当前应用视觉风格保持一致。

## 发布验收

- `package.json`、`package-lock.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock` 与 `src-tauri/tauri.conf.json` 版本号统一为 `0.9.0`。
- Windows 发布产物必须包含 NSIS 安装包与 MSI 安装包，文件名版本号为 `0.9.0`。
- Git tag 与 GitHub Release 使用 `v0.9.0`。
